# Project instructions

## Mandatory storyboard-first workflow (animation & video)

Before creating any animation or video, you MUST create a complete visual storyboard.
Never start video production immediately after receiving a creative brief.
Storyboard approval is a mandatory production gate, not an optional recommendation.

### Phase 1 — Storyboard

1. Analyse the creative brief.
2. Establish the visual direction and creative concept.
3. Divide the video into scenes.
4. Define the duration of each scene.
5. Describe every important animation and camera movement.
6. Specify transitions, lighting, typography, colours and effects.
7. Generate storyboard images for each scene.
8. Present the complete storyboard for review.

### Phase 2 — User approval

STOP production after presenting the storyboard and wait for explicit approval from the user.
The user can:

- Approve the storyboard.
- Request changes to individual scenes.
- Request a complete redesign.

Do not write the final animation or render the video before approval.

### Phase 3 — Production (only after approval)

1. Select appropriate animation techniques from the available repositories.
2. Develop the animation using suitable technologies (Three.js, GSAP, SVG, CSS, Remotion).
3. Follow the approved storyboard accurately.
4. Implement camera movements, transitions, effects and sound design.
5. Generate a preview.

### Phase 4 — Final delivery (after preview approval)

- Render the final video.
- Maintain the approved aspect ratio and resolution.
- Export the final MP4.
- Deliver all relevant project files.
